# RU-Draft-Adaptation: русификация DFlash2-драфткара на одном железе

[![status](https://img.shields.io/badge/status-pilot%20R3--ready-orange)]()
[![stack](https://img.shields.io/badge/stack-llama.cpp%20b12345%20%2B%20torch%20cu121-blue)]()
[![hardware](https://img.shields.io/badge/hardware-1%C3%97RTX%20407TiS%2016GB%20%2B%2032GB%20RAM-green)]()

**Проблема:** спекулятивные драфты (DFlash2) обучены на EN-корпусах и
теряют acceptance на русском. Измерено на боевом стеке (Occamy-1.0
35B-A3B + incoai DFlash2): **RU-код 45.5% против EN 64.3% (−18.8пп)** —
рычаг спекулятивного декода на профиле «русский агентный» сжат на треть.

**Решение:** дообучение готовой драфт-карты на выхлопе **боевого
инференса** — учитель = рабочий квант ствола (распределение ≈ BF16),
фичи снимаются патченным `llama-imatrix` через публичный API
`llama_set_embeddings_layer_inp` (тот самый буфер, которым движок кормит
драфта в прод-спекуляции). Внешнее железо не нужно. RU-драфтов не
существует ни у кого.

## Пайплайн

```
код-репо ──> RU-задачи (коммиты/review/терминология)
                │
                ▼
     боевой инференс :1234 (ствол + НЕ-ру драфт для скорости,
                │     rejection-семплинг сохраняет распределение)
                ▼
        корпус 700К+ токенов (thinking включён)
                │
                ▼
     патченный llama-imatrix: дамп входов 8 слоёв ствола
     + top-16 логитов + frozen fc-проекция (DFSH-поток)
                │
                ▼
     train_draft.py: блоки 16 ток, soft-CE к top-k учителя,
     fc/selector/словарь заморожены (путь jzinno)
                │
                ▼
     export_gguf.py → BF16 → llama-quantize (карта tier1)
                │
                ▼
     ГЕЙТ: t35langacc 4 ячейки, greedy:
     успех = RU-код ≥55% И EN-код ≥62% (анти-перетрен)
```

## Ключевые числа пилота (15.11)

- Базовая дыра: enc 64.3 / **ruc 45.5** / ent 51.0 / rut 43.9 % acc
- Корпус: 240 диалогов, 664К ток., симуляция на 2 репозиториях
- Дамп: 696 320 токенов фич+top-16 (5.8 ГБ), SANITY ок
- Деквант таблиц: 668/668 против движка, max|Δ|=6e-5
- Полный цикл: ~13 ч (повторные — 4–5 ч)
